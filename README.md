# HANI 4 BODY

HANI 4 BODY는 최근 2주 동안의 몸 상태를
한의학의 기(氣)·혈(血)·음(陰)·양(陽) 관점에서 살펴보는
대중용 자가점검 웹앱입니다.

## 주요 기능

- 기(氣)·혈(血)·음(陰)·양(陽) 4가지 점수 확인
- 최근 상태를 레이더 차트로 시각화
- 풀밸런스 / 균형양호 / 부족형 결과 분류
- 결과 뱃지 저장 및 공유
- QR코드를 통한 친구 검사 공유
- 친구 결과 비교
- 내 지난 검사 기록 확인
- 가까운 동네한의원 안내

## 결과 기준

- 기·혈·음·양 모두 90점 이상 → 풀밸런스
- 모두 80점 이상 → 균형양호
- 그 이하는 부족형
