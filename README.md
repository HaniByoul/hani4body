# HANI 4 BODY

HANI 4 BODY는 최근 2주 동안의 몸 상태를 한의학의 기(氣)·혈(血)·음(陰)·양(陽) 관점에서 살펴보는 대중용 탐색적 자가점검 웹앱입니다.

- 기(氣): 활력과 회복력
- 혈(血): 영양과 안정
- 음(陰): 촉촉함과 회복 자원
- 양(陽): 온기와 추진력

기·혈·음·양은 특정 장기나 하나의 검사수치와 1:1로 대응되는 개념이 아니라, 여러 증상과 신체 상태를 종합해 바라보는 한의학적 기능 개념입니다.

## 현재 점수 방식

문항의 의미와 중복성을 고려해 가중치를 적용합니다.

- 흔하거나 다른 원인으로도 쉽게 나타나는 증상: 낮은 가중치
- 비교적 기·혈·음·양의 특징을 잘 보여주는 증상: 높은 가중치
- 설질 창백, 치흔, 설열은 보조 관찰 소견으로 반영

현재 결과 분류는 다음과 같습니다.

- 네 축 모두 90점 이상: 풀밸런스
- 네 축 모두 70점 이상: 균형양호
- 70점 미만인 축: 부족 경향 조합으로 상태 표현
- 네 축이 모두 70점 미만이어도 곧바로 '올다운'으로 분류하지 않고 가장 낮은 축을 중심으로 해석
- '올다운'은 네 축이 모두 40점 이하이면서 네 축 평균이 35점 미만일 때만 사용

이 기준은 임상 진단 기준이 아니라 HANI 4 BODY의 탐색적 자기점검 및 시각화를 위한 운영 기준이며, 향후 실제 참여자 데이터와 타당도 검토에 따라 조정될 수 있습니다.
